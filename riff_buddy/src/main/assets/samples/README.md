# Sample files

Bundled so the tab library has something to open on first use, and so
`TabFormatsTest` and `TabLibraryTest` can test all three format families without
a license question. All three are original work for Riff Buddy; nothing here is
transcribed from a recording.

| File | Format | How it was made |
|---|---|---|
| `pentatonic-study.alphatex` | alphaTex | Written by hand. Twelve bars, two tracks (guitar, bass), E minor pentatonic, 96 BPM. Twelve bars so the "loop over bars 5–8" sits in the middle; two tracks so mute and solo have something to act on. |
| `pentatonic-study.gp` | Guitar Pro 7 | The alphaTex file above, written out by alphaTab's own `Gp7Exporter`. It proves the `.gp` import path, but it is alphaTab reading its own writing — a Guitar Pro file from Guitar Pro itself is the stronger test, and that has to be one of the player's own. |
| `a-minor-blues.musicxml` | MusicXML 4.0 | Generated by a short script so every pitch agrees with its string and fret. Eight bars, one track, A minor, 84 BPM. The first version had no `<staff-details>` tuning and crashed alphaTab's sound pass on both devices; that version is kept as a test fixture under `src/test/resources/tabs/`. |

To regenerate the `.gp`: load the alphaTex with `ScoreLoader.loadAlphaTex`, pass
the score to `Gp7Exporter().export(...)`, write the bytes. A throwaway JVM test
did exactly that; it was deleted once the file existed.

## Sample recordings (looper, the spec)

Generated by `tools/make_sample_audio.py` — standard-library Python, rerunnable.
Original and synthesized, so no license question. 22.05 kHz mono WAV.

| File | What it is for |
|---|---|
| `a440-test-tone.wav` | 15 s of A440. The device check: play it at 50 % on one device, read it with the tuner on the other. A working stretcher shows A; a naive slow-down shows the A an octave below. `LoopRendererTest` runs this exact file through the stretcher and the tuner's detector. |
| `pentatonic-riff.wav` | The Pentatonic Study's first eight bars as plucked guitar and bass (Karplus-Strong), 96 BPM — for loops, the trainer, count-in and the metronome. |

They exist because the looper plays recordings the player already has, and
a phone whose music is streamed has none: M9 could not be tried until M10's
recorder existed.
